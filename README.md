# wp-auto-plugins

A growing collection of production-ready WordPress plugins — automatically generated, tested, and reviewed using the [AutoPush](https://github.com/RakeshRaushan403/autopush) pipeline.

---

## How plugins get here

Every plugin in this repository passed a strict 4-gate quality pipeline before being published:

| Gate | What it checks | How |
|------|---------------|-----|
| **Gate 1** | PHP syntax — no parse errors, no bad brackets | `php -l` on every file |
| **Gate 2** | WordPress activation — plugin activates without crashing | WP-CLI in a real WordPress environment |
| **Gate 3** | Manual review — main feature actually works | Installed and tested on a local WordPress site |
| **Gate 4** | Final publish | Approved via GitHub Issue label |

Plugins that fail any gate are automatically fixed by Claude (up to 5 attempts) before being discarded and regenerated. Nothing reaches this repo without passing all four gates.

---

## Pipeline schedule

| Day | What happens |
|-----|-------------|
| **Monday 10:00 UTC** | Claude generates a new plugin idea, writes the code, runs automated tests, stages it |
| **Tuesday** | Manual testing on LocalWP — approve or reject via GitHub Issue |
| **Wednesday 10:00 UTC** | Approved plugins are published here. Rejected ones are discarded. |

## Using a plugin

Each plugin folder contains:
- The main `.php` file — upload to `/wp-content/plugins/` and activate
- A `README.md` — full installation and usage guide written in plain English

**To install:**
1. Click into any plugin folder under `plugins/`
2. Download the `.php` file
3. In your WordPress admin go to **Plugins → Add New → Upload Plugin**
4. Upload the file and click **Activate**

## Tech stack

Plugins are generated by **Claude Sonnet** via the Anthropic API and tested automatically using **WP-CLI** inside GitHub Actions. The pipeline is built with Node.js and runs entirely on GitHub's free tier.

- **AI model:** claude-sonnet-4-5
- **Languages:** PHP, PHP+JS, PHP+React (Gutenberg blocks)
- **Coding standards:** WordPress coding standards — sanitized inputs, escaped outputs, nonces on all forms, HPOS-compatible for WooCommerce plugins
- **Automated by:** [AutoPush](https://github.com/RakeshRaushan403/autopush)
